## 🚀 Overview

**Kashier System** is a desktop point-of-sale (POS) application for **retail shops, factories, and small to medium-sized businesses**.

It keeps the cashier's work simple: find a product, add it to the invoice, take the payment, done. Behind the scenes it keeps products, invoices and daily sales organised, so the owner always knows what was sold today.

## 🛠️ Technology & architecture

| Layer | Technology |
|---|---|
| Language | **C#** |
| UI | **WPF (.NET)** |
| Architecture | **MVVM**: views, view models and models kept separate, so screens stay clean and logic stays testable |
| Platform | **Windows** desktop |

```
Kashier System
├── Views        → WPF screens (XAML)
├── ViewModels   → screen logic, commands, data binding
└── Models       → products, invoices, sales
```
